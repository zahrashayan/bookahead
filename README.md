# BookAhead

Predictive flight-pricing capstone & prototype.

## Goal
Build a product-ready tool that recommends whether to **buy now** or **wait** for a flight.

## Repo structure
- `data/` — raw and cleaned datasets (raw ignored from git)
- `notebooks/` — exploratory notebooks
- `src/` — data collection & preprocessing scripts
- `model/` — training & modeling code
- `interface/` — prototype frontend/backend
- `docs/` — data sources, decisions, and notes

## Quick start (local)
1. Clone repo
2. Create & activate python venv: `python3 -m venv venv && source venv/bin/activate`
3. Install: `pip install -r requirements.txt`
4. See `notebooks/01-data-exploration.ipynb`
